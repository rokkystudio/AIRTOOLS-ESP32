# AIRTOOLS ESP32-C6 v0.2.2

Выпуск прошивки для профиля `esp32-c6-touch-lcd147` с обновлённым форматом передачи имён Wi-Fi и экраном состояния.

## Изменения относительно v0.2.1

- `/networks` объявляет `ssid_encoding=hex` и передаёт сохранённые байты SSID шестнадцатеричными символами. Такой формат не зависит от корректности UTF-8 в имени точки доступа.
- Версия `v0.2.2` на дисплее выводится шрифтом того же размера, что и заголовок AIRTOOLS.
- В ответе `/status` публикуется `firmware=0.2.2` и `version=0.2.2`.
- Числовая версия в конфигурации PlatformIO — `0x000202`.

## Совместимость

- ESP32-C6, профиль `esp32-c6-touch-lcd147`, JD9853 1.47", 8 MB flash.
- Android-приложение AIRTOOLS v1.14 или новее интерпретирует формат SSID `hex`; старые клиенты не поддерживают этот формат.
- Соглашение BLE, UUID и маркер конца ответа не меняются.

## Проверка

- `pio run -e esp32-c6-touch-lcd147` — успешная сборка.
- Изменения формата SSID описаны в `docs/protocol.md`.

В публичные вложения включён только патч исходных изменений данного выпуска. Бинарные модификации vendor-библиотеки, затрагивающие ограничения передачи Wi-Fi management-кадров, не входят в этот пакет.
